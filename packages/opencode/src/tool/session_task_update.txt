Update the status or details of a single task in your session task list.

- Provide the `id` of the task to update.
- Set `status` to one of: "pending", "in_progress", "completed", "cancelled".
  - Do NOT set status to "blocked" manually — it is set automatically when dependencies are unresolved.
- Optionally update `content`, `priority`, or `depends_on`.

Guidelines:
- Mark tasks "in_progress" when you start working on them. Only ONE task should be in_progress at a time.
- Mark tasks "completed" IMMEDIATELY after finishing — do not batch completions.
- When a task is completed, any tasks that depend on it are automatically unblocked.
- Cancel tasks that become irrelevant.
